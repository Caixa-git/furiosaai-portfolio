# ⚖️ Naruhodo — 법률/라이선스 검토 엔진

> Alchemy Agent 스킬 #15 — 법적·권리·라이선스·개인정보 리스크 검토 전문 엔진. 11항목 체크리스트 기반 전수 검사로 법적 리스크를 조기에 발견하고, Risk Score(0–10)로 종합 위험도를 정량화한다.

## 개요

Naruhodo 스킬은 프로젝트·제품·코드베이스에 내재된 법적 리스크를 11항목 체크리스트로 전수 검사한다. 오픈소스 라이선스 호환성, 개인정보보호법(GDPR·CCPA·한국 개인정보보호법) 준수, 상표권·저작권·특허 침해 가능성, 이용약관(TOS) 적합성 등 법적 전 영역을 포괄한다. 각 항목별로 통과/경고/위험 3단계 판정을 내리고, Risk Score 0–10으로 종합 리스크 수준을 제공한다.

## 핵심 기능

| 기능 | 설명 |
|:-----|:------|
| **11항목 체크리스트** | ①라이선스 호환성(GPL/MIT/Apache/BSD) ②라이선스 의무사항(고지·소스 공개) ③저작권 침해 ④상표권 침해 ⑤특허 침해 ⑥GDPR 준수 ⑦CCPA 준수 ⑧한국 개인정보보호법 준수 ⑨데이터 처리 흐름(수집·저장·전송) ⑩이용약관(TOS) 적합성 ⑪제3자 API/서비스 법적 조건 — 각 항목 통과/경고/위험 판정 |
| **Risk Score 0–10** | 11항목 결과를 가중치 합산한 종합 위험도 — 0–3(안전), 4–6(주의), 7–8(경고), 9–10(심각) 구간 분류, 항목별 세부 위험 요소 리스트 제공 |
| **오픈소스 라이선스 분석** | 의존성 트리 탐색 → 각 패키지의 라이선스 식별 → 충돌하는 라이선스 조합(GPL + Apache 등) 감지 → 의무사항(고지문 포함·소스 코드 공개 범위) 자동 체크리스트 생성 |
| **개인정보 리스크 분석** | 데이터 수집 동의 프로세스·저장 기간·국제 전송·삭제 정책 등 GDPR/CCPA/한국법 교차 분석, 개인정보 영향평가(PIA) 초안 자동 생성 |
| **권리 침해 감지** | 상표명·브랜드명·코드 내 식별자 검색 → 등록 상표/저작권과의 충돌 가능성 탐색, 오픈소스 코드 복사 여부(git blame + provenance) 분석 |
