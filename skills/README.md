## 공통 구조

모든 스킬은 다음 계약을 따릅니다:

```yaml
# 예시: YAML frontmatter 스키마
name: <스킬명>
version: <semver>
trigger: <호출 조건>
input:
  format: PIPE Protocol (JSON)
  schema: { ... }
output:
  format: PIPE Protocol (JSON)
  schema: { ... }
dependencies: [ <의존 스킬 목록> ]
```

Pipeline 연동:

```
Socrates(진단) → Router(경로 선택) → Pipeline(실행)
     ↕                              ↕
  Skill Engine               PIPE Protocol
```
