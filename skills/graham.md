# 📊 Graham — Early Sales 압력 테스트

> Alchemy Agent 스킬 #12 — 초기 아이디어·제품의 시장 검증 및 판매 가능성 압력 테스트. Graham Score(0–10)로 문제-해결 적합성과 고객 확보 가능성을 정량화한다.

## 개요

Graham 스킬은 Paul Graham의 스타트업 철학에 기반한 **Early Sales 압력 테스트** 엔진이다. "이 제품이 없으면 불편한가 vs. 있으면 좋은가"라는 핵심 질문을 중심으로, 아이디어 단계의 제품이 실제로 판매될 수 있는지 3대 검증 축(고객 문제, 판매 가능성, 첫 10명)에서 평가한다. 결과는 Graham Score 0–10으로 정량화되어 의사결정을 지원한다.

## 핵심 기능

| 기능 | 설명 |
|:-----|:------|
| **Graham Score 0–10** | 3대 검증 축 통합 점수: (1) **고객 문제(Customer Problem)** — 문제의 긴급성·빈도·지불 의향, (2) **판매 가능성(Sellability)** — 판매 채널·가격 적정성·구매 결정권자 접근성, (3) **첫 10명(First 10)** — 얼리어답터 식별·수동 확보 가능성·최초 레퍼런스 전략 |
| **압력 테스트 질문** | "이 제품이 없으면 어떤 구체적 불편이 발생하는가?" / "대안(수동 해결·경쟁 제품)이 이미 존재하는가?" / "고객이 진짜 돈을 지불할 의사가 있는가?" — 질문 응답에 따라 점수 가감 |
| **경쟁사 비교 매트릭스** | 기능·가격·사용자 경험·전환 비용 4축 경쟁사 비교표 자동 생성, 차별화 포인트 및 방어 가능한 포지셔닝 제안 |
| **리스크 식별** | 기술 리스크(구현 난이도), 시장 리스크(수요 부재), 실행 리스크(팀 역량) — 3대 리스크 축별 완화 전략 수반 |
| **PIPE Protocol 연동** | 평가 결과를 JSON 구조로 출력 → Router/Socrates 스킬이 의사결정 흐름에 활용 |
