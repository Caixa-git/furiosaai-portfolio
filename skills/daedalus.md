# 🛠️ Daedalus — MCP/도구 설계 엔진

> Alchemy Agent 스킬 #14 — MCP 서버 및 AI 에이전트 도구 설계·제작 전문 엔진. Tool Score(0–10)로 도구의 설계 품질과 에이전트-도구 인터페이스 적합성을 정량 평가한다.

## 개요

Daedalus 스킬은 AI 에이전트가 사용할 MCP(Model Context Protocol) 서버 및 도구를 설계·제작하는 전문 엔진이다. **Prompt-First** (프롬프트 정의 → 도구 구현)와 **Mock-First** (모의 서버 → 실제 구현)라는 두 가지 설계 원칙을 따르며, 설계된 도구의 품질을 Tool Score로 정량화한다. JSON-RPC 2.0 기반 MCP 프로토콜 스키마 설계부터 생성형 AI 도구 명세 자동화까지 포괄한다.

## 핵심 기능

| 기능 | 설명 |
|:-----|:------|
| **MCP 서버 설계** | JSON-RPC 2.0 기반 Model Context Protocol 서버 — 도구/리소스/프롬프트 3종 엔드포인트 스키마 자동 설계, 인증·에러 코드·페이지네이션 명세 포함 |
| **Tool Score 0–10** | 도구 설계 품질 5축 평가: (1) **명확성** — 입출력 타입 및 동작 설명의 명확도, (2) **안정성** — 오류 처리·타임아웃·재시도 로직 완비도, (3) **확장성** — 새 기능 추가 용이성 및 버전 호환성, (4) **효율성** — 불필요한 왕복·데이터 중복 최소화, (5) **에이전트 적합성** — LLM이 도구를 정확히 호출할 수 있는 인터페이스 설계 |
| **Prompt-First 원칙** | 도구의 사용 사례와 호출 프롬프트를 먼저 설계한 후, 프롬프트에서 요구하는 입출력에 맞춰 구현 — LLM이 자연어로 도구를 정확히 사용할 수 있도록 보장 |
| **Mock-First 원칙** | 실제 구현 전에 모의(mock) MCP 서버를 먼저 구축하여 프로토타입 검증 — 인터페이스 오류 조기 발견 및 에이전트-도구 통합 테스트 자동화 |
| **도구 명세 자동화** | 사용 사례(use case) 기술 → 자동 OpenAPI/Schema 생성 → 에이전트 레지스트리 등록까지 전 과정 자동화 |

## 버전 정보

- **버전**: v0.1.0 (초기 설계)
- **상태**: 설계 단계
- **트리거 조건**: 신규 MCP 서버 또는 도구 설계 요청 시, 기존 도구의 품질 검토 요청 시
- **의존 스킬**: Prometheus (스킬 메타), Hephaestus (빌드/테스트)
