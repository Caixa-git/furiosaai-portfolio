# 🎯 Athena — 채용/이력서 맞춤 전략

> Alchemy Agent 스킬 #13 — 채용공고 분석 및 이력서·자기소개서 맞춤 전략 수립. Match Score(0–10)로 지원자-공고 간 적합도를 정량화하고, C++/Windows/보안/암호 도메인에 특화된 분석을 제공한다.

## 개요

Athena 스킬은 채용공고(JD)를 심층 분석하여 핵심 요구사항을 추출하고, 지원자의 이력서/포트폴리오와의 매칭률을 정량화한다. **C++·Windows 시스템·보안·암호학** 도메인에 특화되어 있어, 시스템 소프트웨어·임베디드·보안 엔지니어링 포지션에 대한 정밀한 적합도 평가가 가능하다. Match Score는 기술 적합도와 경험 적합도를 분리 측정하여 약점을 구체적으로 진단한다.

## 핵심 기능

| 기능 | 설명 |
|:-----|:------|
| **채용공고 분석** | JD에서 필수 요구사항(기술 스택·경력·자격증)과 우대사항(도메인 지식·소프트스킬)을 자동 분류·추출, 키워드 중요도 가중치 부여 |
| **Match Score 0–10** | 기술 적합도(Tech Fit) + 경험 적합도(Experience Fit) 이중 점수 체계 — C++(표준/템플릿/STL), Windows(API/드라이버/커널), 보안(취약점 분석/암호 구현), 암호학(대칭/공개키/프로토콜) 4개 세부 축 평가 |
| **맞춤 전략** | 약점 보완 포트폴리오 제안(오픈소스 기여·개인 프로젝트·기술 블로그), 자기소개서 핵심 키워드 및 경험 서술 방향 추천, 면접 예상 질문 및 대비 전략 |
| **도메인 특화 프로파일링** | C++/Windows/보안/암호 4대 도메인별 역량 레벨(Junior/Mid/Senior/Principal) 매핑, 경력 기간 대비 기대 역량과 실제 역량 간 갭 분석 |
| **PIPE Protocol 연동** | 분석 결과를 JSON(PIPE Protocol)으로 구조화 → Router/Socrates가 종합 전략 수립에 활용 |

## 버전 정보

- **버전**: v0.1.0 (초기 설계)
- **상태**: 설계 단계
- **트리거 조건**: 채용공고 URL 또는 텍스트 입력 시, 이력서 첨부 시 매칭 분석 자동 실행
- **의존 스킬**: Columbus (회사·직무 시장 조사), Sherlock (경쟁 지원자 분석)
