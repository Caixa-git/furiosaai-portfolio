# 📚 Library — 지식 관리 엔진

> Alchemy Agent 스킬 #11 — 문서 기반 지식 흡수도 측정 및 지식 그래프 관리. Full Read Score와 Library Value Score라는 이중 정량 지표로 지식의 **입력(Read)** 과 **출력(Value)** 을 동시에 평가한다.

## 개요

Library 스킬은 에이전트가 축적한 문서/레퍼런스 지식의 질적 수준을 진단한다. 단순히 저장된 문서 수가 아니라, 사용자가 실제로 **얼마나 깊이 읽었는지(Full Read Score)** 와 저장된 지식이 **실제 문제 해결에 얼마나 재사용되었는지(Library Value Score)** 를 각각 0–10 척도로 정량화한다. Read/Search/Store 3분기 판단 모델로 지식 관리 결정을 자동화한다.

## 핵심 기능

| 기능 | 설명 |
|:-----|:------|
| **Full Read Score** | 문서 완독률 기반 지식 흡수도 측정 — 단순 스캔(10% 미만) vs. 부분 독해(10–80%) vs. 정독 완료(80%+) 구분, 문서 길이 가중치 적용 |
| **Library Value Score** | 저장된 지식의 실질적 활용도 평가 — 참조 횟수, 재사용률, 문제 해결 기여도 기반 0–10 정량화 |
| **Read / Search / Store 판단** | 지식 관리 3분기 의사결정: (1) **Read** — 새 문서를 정독할 가치가 있는가? (2) **Search** — 기존 지식 검색으로 충분한가? (3) **Store** — 이 지식을 저장소에 추가해야 하는가? |
| **지식 그래프 분석** | 저장된 지식 간 연결 관계를 그래프로 시각화, 학습 격차(gap) 자동 탐지 및 미보유 지식 추천 |
| **PIPE Protocol 연동** | 모든 판단 결과를 JSON(PIPE Protocol)으로 구조화하여 다른 스킬(Router, Socrates)이 소비 가능 |

## 버전 정보

- **버전**: v0.1.0 (초기 설계)
- **상태**: 설계 단계
- **트리거 조건**: 지식 검색/저장 요청 시, 또는 정기적 지식 감사(Knowledge Audit) 주기 도래 시
- **의존 스킬**: Columbus (검색), Sherlock (레포 분석)
