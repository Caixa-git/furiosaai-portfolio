# CRAFT 프레임워크

> **CRAFT** — 자율 에이전트를 위한 계층형 파이프라인 프레임워크

## 개요

CRAFT는 대규모 언어 모델(LLM) 기반 자율 에이전트의 추론, 행동, 자기 개선을 체계적으로 orchestration하기 위한 프레임워크입니다. 19개 학술 논문에서 도출된 원리를 바탕으로 설계되었으며, 에이전트가 복잡한 작업을 안정적이고 비판적으로 수행할 수 있도록 9계층 파이프라인 구조를 제공합니다.

CRAFT는 단순한 프롬프트 체인이 아닌, **CRITICALITY 점수 시스템**, **FIRE 필터(자기 비판 메커니즘)**, **사용자 개입 조건** 등을 통해 에이전트의 자율성과 안전성을 동시에 확보합니다.

---

## 발전 과정

CRAFT 프레임워크는 세 단계의 진화를 거쳐 발전했습니다.

```
CRAFT (기본)
  └─→ POWER CRAFT (스킬 도구)
       └─→ SUPER POWER CRAFT (포트폴리오 통합)
```

### 1. CRAFT — 9계층 자율 파이프라인

CRAFT의 핵심인 9계층 파이프라인은 에이전트의 작업 수행 과정을 단계별로 분해하여 제어합니다.

| 계층 | 명칭 | 설명 |
|------|------|------|
| L1 | **입력 분석** (Input Analysis) | 사용자 요청을 구문 분석하고 의도 파악 |
| L2 | **컨텍스트 구축** (Context Building) | 관련 정보와 이전 맥락 수집 |
| L3 | **계획 수립** (Planning) | 작업 수행을 위한 단계별 계획 생성 |
| L4 | **실행** (Execution) | 계획에 따라 도구 호출 및 작업 수행 |
| L5 | **CRITICALITY 평가** (Criticality Scoring) | 결과물의 중요도와 영향력 점수화 |
| L6 | **FIRE 필터** (Self-Critique Filter) | 자기 비판을 통한 결과물 검증 및 개선 |
| L7 | **사용자 개입 차단** (Intervention Guard) | 4가지 조건에서 사용자 개입 요청 차단 |
| L8 | **통합 검증** (Integration Validation) | 전체 흐름의 일관성과 완결성 검증 |
| L9 | **출력** (Output) | 최종 결과물 포맷팅 및 반환 |

#### 핵심 메커니즘

- **CRITICALITY 점수 시스템** — 각 단계의 결과물에 대해 0.0~1.0 범위의 중요도 점수를 부여하여, 에이전트가 어떤 부분에 더 집중해야 하는지 판단하도록 함.
- **FIRE 필터 (Factual Integrity & Reflective Evaluation)** — 자기 비판(self-critique)을 통해 에이전트가 자신의 출력을 검증하고 오류를 수정. 환각(hallucination) 감지 및 논리적 일관성 확인에 사용.
- **사용자 개입 4가지 조건 차단** — 사용자가 개입을 요청할 수 있는 상황을 4가지로 제한하여 불필요한 중단을 방지하고 자율성을 극대화.

### 2. POWER CRAFT — 고급 스킬 제작 도구

POWER CRAFT는 CRAFT의 기능을 확장하여 에이전트가 **스킬을 직접 제작, 병합, 마스터**할 수 있는 도구 세트를 제공합니다.

| 도구 | 설명 |
|------|------|
| **스킬 제작** (Skill Forge) | 새로운 스킬을 정의하고 등록. 기존 패턴과 템플릿 기반으로 빠르게 제작 가능 |
| **스킬 병합** (Skill Merge) | 두 개 이상의 스킬을 지능적으로 병합하여 새로운 복합 스킬 생성 |
| **스킬 마스터** (Skill Master) | 기존 스킬을 분석하고 최적화하여 성능 향상 |

POWER CRAFT를 통해 에이전트는 고정된 도구 세트에 의존하지 않고, 필요에 따라 스스로 도구를 확장하고 개선할 수 있습니다.

### 3. SUPER POWER CRAFT — 전체 포트폴리오 통합

SUPER POWER CRAFT는 CRAFT와 POWER CRAFT를 통합하여 **에이전트의 전체 포트폴리오를 관리**하는 최상위 계층입니다.

| 기능 | 설명 |
|------|------|
| **포트폴리오 관리** | 모든 스킬, 도구, 파이프라인 구성을 중앙에서 관리 |
| **통합 오케스트레이션** | CRAFT 파이프라인과 POWER CRAFT 도구를 조율하여 복잡한 워크플로우 실행 |
| **성능 모니터링** | 각 스킬과 계층의 성능을 지속적으로 추적 및 분석 |
| **자동 최적화** | 사용 패턴과 성능 데이터를 기반으로 파이프라인과 스킬을 자동 조정 |

SUPER POWER CRAFT는 단일 에이전트를 넘어 **다중 에이전트 시스템**과의 통합도 지원하여, 확장 가능한 자율 시스템을 구축할 수 있는 기반을 제공합니다.
